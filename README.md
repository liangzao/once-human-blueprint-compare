# 七日世界 · 精校图纸对比工具

一个本地优先的网页小工具：录入《七日世界》（Once Human）武器精校图纸数据，综合**最高伤害**与**出伤稳定程度**两个维度评分，在多张图纸之间自动挑出综合最优的一张。

## 功能

- 📝 **图纸录入**：名称、适用武器、品质、主词条攻击力加成（%）、副词条（暴击率 / 暴击伤害 / 弱点伤害 / 元素伤害 四选一，%），支持截图附件与备注
- 📥 **数据上传/导入**：支持 JSON 文件批量导入导出，方便分享与备份
- 📊 **评分对比**：柱状图对比综合分 / 最高伤害分 / 稳定度
- 🏆 **最佳推荐**：排行榜 + 综合最优高亮推荐
- ⚖️ **可调评分模型**：最高伤害权重 vs 出伤稳定权重自由调节；基础暴击面板、弱点命中率系数可调
- 📱 **手机端适配**：响应式布局，手机上也能正常录入和查看
- 💾 **本地保存**：数据存在浏览器 localStorage，不上传服务器

## 评分模型

图纸结构：**主词条固定为攻击力加成（%）+ 一条副词条（%）**，所有数值均为确切值。

**伤害模型**：

- 基础倍率 = (1 + 攻击力加成) × (1 + 元素伤害加成)，全程生效、无波动
- 暴击因子期望 = 1 + 暴击率 × 暴击伤害，波动 = √(p(1−p)) × 暴击伤害
- 弱点因子期望 = 1 + 弱点命中率 × 弱点伤害，波动 = √(q(1−q)) × 弱点伤害

**最高伤害倍率** = 基础 × (1+暴击伤害) × (1+弱点伤害)（暴击与弱点同时触发的爆发上限）

**稳定度** = 期望伤害 ÷ (期望伤害 + 波动) × 100（越接近 100 出伤越稳；元素伤害类图纸无额外波动，稳定度最高）

**综合分** = 伤害权重 × 最高伤害分 + 稳定权重 × 稳定度

评分只考虑最高伤害与出伤稳定两个维度，不引入其它指标。

## 本地运行

```bash
npm install
npm run dev      # 开发预览
npm run build    # 生产构建 → dist/
```

技术栈：React + TypeScript + Vite + Tailwind CSS + shadcn/ui + Recharts

## JSON 导入格式

```json
[
  {
    "name": "图纸A · 暴击率",
    "weapon": "大白鲨",
    "rarity": "传说(金)",
    "attack": 15,
    "subAttrId": "crit_rate",
    "subValue": 12.5
  }
]
```

- `attack`：主词条攻击力加成（%）
- `subAttrId`：`crit_rate`（暴击率）、`crit_dmg`（暴击伤害）、`weakspot_dmg`（弱点伤害加成）、`elemental_dmg`（元素伤害加成）
- `subValue`：副词条数值（%）
