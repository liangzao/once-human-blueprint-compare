# 七日世界 · 精校图纸对比工具

一个本地优先的网页小工具：录入《七日世界》（Once Human）武器精校图纸的词条 roll 区间，综合**最高伤害**与**出伤稳定程度**评分，在多张图纸之间自动挑出综合最优的一张。

## 功能

- 📝 **图纸录入**：名称、适用武器、品质、词条 roll 区间（下限~上限）、截图附件、备注
- 📥 **数据上传/导入**：支持 JSON 文件批量导入导出，方便分享与备份
- 📊 **多维对比**：柱状图对比综合分/伤害上限/期望伤害/稳定度，雷达图任选图纸对比
- 🏆 **最佳推荐**：排行榜 + 综合最优高亮推荐
- ⚖️ **可调评分模型**：最高伤害权重 vs 出伤稳定权重自由调节；弱点命中率、特攻覆盖率系数可调
- 💾 **本地保存**：数据存在浏览器 localStorage，不上传服务器

## 评分模型

**伤害指数**：把伤害类词条折算成综合伤害倍率

- 武器伤害 / 元素伤害：独立乘区
- 暴击率 × 暴击伤害：`1 + 暴击率 × 暴击伤害`（暴击率封顶 100%）
- 弱点伤害：乘以弱点命中率系数（默认 60%）
- 对精英/畸变体/首领伤害：乘以覆盖率系数（默认 70%）
- 其他加伤：统一加区
- 换弹、弹匣等辅助词条不参与伤害计算

**稳定度** = 最低 roll 伤害 ÷ 满 roll 伤害 × 100（越接近 100 出伤越稳）

**综合分** = 伤害权重 × 伤害上限分 + 稳定权重 × 稳定度

## 本地运行

```bash
npm install
npm run dev      # 开发预览
npm run build    # 生产构建 → dist/
```

技术栈：React + TypeScript + Vite + Tailwind CSS + shadcn/ui + Recharts

## JSON 导入格式

```json
[
  {
    "name": "图纸A · 双暴流",
    "weapon": "大白鲨",
    "rarity": "传说(金)",
    "entries": [
      { "attrId": "weapon_dmg", "min": 12, "max": 18 },
      { "attrId": "crit_rate", "min": 8, "max": 12 },
      { "attrId": "crit_dmg", "min": 20, "max": 30 }
    ]
  }
]
```

`attrId` 可选值见 `src/types/blueprint.ts` 中的 `ATTR_CATALOG`。
